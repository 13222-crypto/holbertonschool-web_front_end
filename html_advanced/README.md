# Advanced HTML

## Description
This project focuses on learning how to use HTML tags to structure a web page properly. It covers semantic HTML5 tags, page structure, media integration (video, audio, images), tables, and modern HTML guidelines without using any CSS styling.

## Learning Objectives
At the end of this project, you should be able to explain:
- HTML guidelines and standards.
- How to create the skeleton of an HTML5 page.
- How to use semantic HTML tags (`<header>`, `<main>`, `<footer>`, `<article>`, `<nav>`, `<section>`, `<aside>`).
- When to use `<div>` vs `<span>`.
- How to use heading tags hierarchically (`<h1>` to `<h6>`).
- How to create ordered and unordered lists.
- Differences between media formats (`SVG`, `GIF`, `PNG`, `JPG`).
- How to structure tabular data using `<table>`.
- How to integrate video and audio files.
- How to embed external content (`<iframe>`).

## Requirements
- All files should be W3C compliant and validated with W3C-Validator.
- Standard project company name: **Techium**.
- No CSS or styling is used in this project.
